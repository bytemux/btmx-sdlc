# btmx-sdlc

This repo describes the btmx-sdlc conventions, templates and skills (`docs/`, `template/`, `skills/`). They apply to the target repos set up with `skill:init-repo`.

## Not applied to this repo yet

The rules this repo describes will be applied to this repo later, as a separate change. Until the user says otherwise, do not account for them here:

- no issue, branch name, PR title or squash-merge rules for work in this repo;
- do not add workflows, pre-commit hooks, rulesets or release files to this repo's root;
- change the templates in `skills/init-repo/config/` only when the user asks for a change to the conventions.
